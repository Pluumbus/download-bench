# Бенчмарк скорости скачивания

Консольный скрипт на Node.js. Он принимает адрес, делает к нему **10 запросов подряд** и каждый раз дожидается полного тела ответа. В конце печатает среднее время запроса, общий объём скачанных данных и скорость.

Зависимостей нет, `npm install` не нужен. Нужен Node.js 18 или новее.

## Запуск по своему адресу

```bash
node bench.js https://example.com/heavy-image.jpg
```

Подойдёт любой `http` или `https` URL: картинка, PDF, Excel или другой файл. Следующий запрос начинается только после того, как предыдущий ответ прочитан до конца.

Пример вывода:

```text
URL: https://example.com/heavy-image.jpg
Запросов: 10, строго по очереди

# 1  HTTP 200      3.42 MB      812.4 мс
# 2  HTTP 200      3.42 MB      790.1 мс
...
#10  HTTP 200      3.42 MB      805.6 мс

Среднее время запроса: 802.3 мс
Скачано всего:         34.20 MB
Скорость скачивания:   4.26 MB/s
```

Если адрес не передан, сервер ответил не `2xx` или соединение оборвалось, скрипт останавливается и завершается с кодом 1.

## Локальные файлы: картинка, PDF и Excel

В каталоге `samples/` лежат три файла примерно по 3 MB:

| Файл | Что это |
| --- | --- |
| `samples/picture.png` | PNG-картинка, 1200×1000 |
| `samples/document.pdf` | PDF с текстом |
| `samples/table.xlsx` | книга Excel, лист «Продажи» |

Их можно скачать заново:

```bash
node generate-samples.js
```

Повторный запуск перезаписывает те же байты. Чтобы отдать файлы по HTTP только на эту машину:

```bash
node serve.js
```

Сервер слушает `127.0.0.1:8080` и отдаёт только содержимое `samples/`. Если порт занят, выберите другой: в PowerShell `$env:PORT=3456; node serve.js`, в bash `PORT=3456 node serve.js`, и подставьте этот порт в адреса ниже. Во втором терминале:

```bash
node bench.js http://127.0.0.1:8080/picture.png
node bench.js http://127.0.0.1:8080/document.pdf
node bench.js http://127.0.0.1:8080/table.xlsx
```

Те же команды через npm-скрипты: `npm run samples`, `npm run serve`, `npm run bench -- http://127.0.0.1:8080/picture.png`.

На `127.0.0.1` скорость упирается в диск и цикл Node, а не в канал провайдера. Для замера сети подставьте внешний URL.

## Единицы

- **Время** — миллисекунды (мс). Это время одного запроса от отправки до последнего байта тела. Среднее — среднее арифметическое десяти запросов.
- **Объём** — мегабайты (MB), где 1 MB = 1 000 000 байт. Считается размер тела ответа, как оно пришло по сети: скрипт просит `Accept-Encoding: identity` и не распаковывает ответ.
- **Скорость** — мегабайты в секунду (MB/s):

```text
скорость = (сумма байт всех ответов) / (сумма времени всех 10 запросов в секундах) / 1 000 000
```

Паузы между запросами нет: в сумму времени входят только сами запросы.

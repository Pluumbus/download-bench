# Бенчмарк скорости скачивания

Консольный скрипт на Node.js. Он принимает адрес, один раз прогревает соединение и затем делает **10 запросов подряд**. Каждый запрос дожидается полного тела ответа. В конце печатает среднее время двух фаз, общий объём скачанных данных и скорость.

Зависимостей нет, `npm install` не нужен. Нужен Node.js 18 или новее.

## Запуск по своему адресу

```bash
node bench.js https://example.com/heavy-image.jpg
node bench.js https://example.com/heavy-image.jpg --timeout 60
```

Подойдёт любой `http` или `https` URL: картинка, PDF, Excel или другой файл. Следующий запрос начинается только после того, как предыдущий ответ прочитан до конца. `--timeout` задаёт предел одного запроса в секундах, по умолчанию 30. В этот предел входит и ожидание ответа, и чтение всего тела.

Пример вывода:

```text
URL: https://example.com/heavy-image.jpg
Запросов: 10, строго по очереди
Прогрев: 1 запрос, в среднее, объём и скорость не входит
Таймаут: 30000 мс на запрос

запрос    HTTP  объём, MB   первый байт, мс  тело, мс  всего, мс
прогрев    200       3.42             180.0     640.0      820.0
#1         200       3.42              40.2     760.1      800.3
#2         200       3.42              38.4     751.0      789.4
...
#10        200       3.42              41.0     764.6      805.6

Среднее до первого байта: 40.1 мс
Среднее скачивание тела:  758.2 мс
Среднее время запроса:    798.3 мс
Скачано всего:            34.20 MB
Скорость скачивания:       4.28 MB/s
```

Прогрев устанавливает соединение и читает файл целиком, но не попадает в средние, объём и скорость. Так холодный первый запрос не завышает результат.

Если адрес не передан, сервер ответил не `2xx`, соединение оборвалось или запрос не уложился в таймаут, скрипт останавливается и завершается с кодом 1.

## Локальные файлы: картинка, PDF и Excel

В каталоге `samples/` лежат три файла примерно по 3 MB:

| Файл | Что это |
| --- | --- |
| `samples/picture.png` | PNG-картинка, 1200×1000 |
| `samples/document.pdf` | PDF с текстом |
| `samples/table.xlsx` | книга Excel, лист «Продажи» |

Их можно скачать заново:

```bash
node generate-samples.js
```

Повторный запуск перезаписывает те же байты. Чтобы отдать файлы по HTTP только на эту машину:

```bash
node serve.js
```

Сервер слушает `127.0.0.1:8080` и отдаёт только содержимое `samples/`. Если порт занят, выберите другой и подставьте его в адреса ниже.

PowerShell:

```powershell
$env:PORT=3456; node serve.js
```

Git Bash:

```bash
PORT=3456 node serve.js
```

Во втором терминале:

```bash
node bench.js http://127.0.0.1:8080/picture.png
node bench.js http://127.0.0.1:8080/document.pdf
node bench.js http://127.0.0.1:8080/table.xlsx
```

Те же команды через npm-скрипты: `npm run samples`, `npm run serve`, `npm run bench -- http://127.0.0.1:8080/picture.png`.

На `127.0.0.1` скорость упирается в диск и цикл Node, а не в канал провайдера. Для замера сети подставьте внешний URL.

## Единицы

- **Время** — миллисекунды (мс). У каждого запроса две фазы. «Первый байт» — от отправки запроса до прихода заголовков ответа, то есть до начала тела. «Тело» — от этого момента до последнего байта. «Всего» — сумма двух фаз. Средние считаются по десяти измеренным запросам, прогрев в них не входит.
- **Таймаут** — миллисекунды на один запрос, в выводе. В аргументе `--timeout` то же ограничение задаётся в секундах. По умолчанию 30 секунд.
- **Объём** — мегабайты (MB), где 1 MB = 1 000 000 байт. Считается размер тела ответа, как оно пришло по сети: скрипт просит `Accept-Encoding: identity` и не распаковывает ответ. Прогрев в сумму не входит.
- **Скорость** — мегабайты в секунду (MB/s):

```text
скорость = (сумма байт 10 ответов) / (сумма времени этих 10 запросов в секундах) / 1 000 000
```

Время запроса здесь — обе фазы вместе. Паузы между запросами нет, прогрев в формулу не входит.
